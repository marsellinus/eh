# Template Konten Poster Ilmiah

Ukuran yang disarankan: A1 portrait atau landscape sesuai template kampus.

## 1. Judul
- Analisis Komparatif CrowdSec vs Fail2Ban dalam Mitigasi Serangan pada Docker Home Server

## 2. Identitas Penulis
- Nama, NIM, Program Studi, Universitas

## 3. Latar Belakang
- Ancaman serangan brute force dan HTTP flood masih tinggi
- Perlunya evaluasi IDPS pada lingkungan container

## 4. Tujuan
- Membandingkan efektivitas deteksi dan pencegahan
- Menganalisis dampak performa resource

## 5. Metodologi
- Lingkungan: Docker compose dengan mode baseline/fail2ban/crowdsec
- Serangan: HTTP flood dan SSH brute force
- Metrik: success/fail attack, detection time, blocked IP, CPU/memory

## 6. Arsitektur / Diagram Sistem
- Tampilkan topologi layanan dan alur log
- Tunjukkan posisi komponen proteksi

## 7. Hasil Utama
- Tabel ringkas perbandingan 3 mode
- Grafik metrik penting (misal detection time, CPU)
- Highlight insight paling signifikan

## 8. Diskusi
- Interpretasi hasil
- Trade-off antara keamanan dan resource

## 9. Kesimpulan
- Solusi yang paling efektif pada skenario penelitian
- Rekomendasi implementasi praktis
