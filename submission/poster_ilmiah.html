Analisis Komparatif Efektivitas CrowdSec versus Fail2Ban dalam Memitigasi Serangan pada Layanan Home Server Berbasis Docker

Program Studi Teknik Informatika  ·  Mata Kuliah Digital Forensics  ·  2026
Docker IDS/IPS SSH Brute-Force HTTP Flood Network Security

Latar Belakang

  • Home server berbasis Docker semakin populer untuk self-hosting layanan pribadi
  • Layanan yang terekspos rentan terhadap serangan otomatis: SSH brute-force dan HTTP flood
  • Dua solusi open-source populer: Fail2Ban (rule-based, iptables) dan CrowdSec (collaborative threat intelligence)
  • Belum ada perbandingan kuantitatif keduanya dalam konteks Docker environment
❓ Mana yang lebih efektif dan efisien untuk home server Docker?

Tujuan & Metodologi

  • Mengukur efektivitas mitigasi SSH brute-force dan HTTP flood secara kuantitatif
  • Membandingkan overhead CPU/memory kedua solusi
  • Menghitung risk score komposit (CVSS-like, 0–10)

Diskusi

  • CrowdSec unggul dalam efektivitas (SSH −35.7%, HTTP −50%) dan risk score (6.62 vs 7.69)
  • Fail2Ban mencatat 0 blocked IPs dan 0 detected events — kemungkinan misconfigurasi log path di Docker
  • Overhead CPU keduanya serupa (~4.4–4.8%) — tidak signifikan untuk home server
  • Semua mode masih HIGH severity — menunjukkan perlunya hardening tambahan
  • HTTP flood menembus semua mode — nginx rate limiting diperlukan sebagai lapisan tambahan
⚠️ Keterbatasan: eksperimen di lab terkontrol, hasil mungkin berbeda di lingkungan produksi dengan traffic nyata

Rekomendasi

CRITICAL
Nonaktifkan password SSH, gunakan key-only auth. Set MaxAuthTries=3.
HIGH
Verifikasi konfigurasi log path Fail2Ban di Docker Compose.
MEDIUM
Tambah nginx rate limiting (limit_req_zone) dan WAF.
LOW
Deploy CrowdSec sebagai lapisan proteksi utama.

Kesimpulan

  • CrowdSec mereduksi SSH login berhasil 35.7% vs baseline (Fail2Ban: 14.3%)
  • CrowdSec mereduksi HTTP 2xx 50% vs baseline (Fail2Ban: 37.5%)
  • CrowdSec lebih efisien: CPU overhead 4.37% vs Fail2Ban 4.81%
  • Risk score CrowdSec lebih rendah: 6.62 vs Fail2Ban 7.69
  • ML RandomForest (NSL-KDD): akurasi 72.16% sebagai pembanding akademik
  • Rekomendasi: CrowdSec + SSH key-only + nginx rate limiting = Defense-in-Depth
