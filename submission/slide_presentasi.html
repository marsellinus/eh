🌐 Latar Belakang

  • Home server berbasis Docker semakin populer untuk self-hosting layanan pribadi
  • Layanan yang terekspos ke jaringan rentan terhadap serangan otomatis
  • SSH brute-force dan HTTP flood adalah dua vektor serangan paling umum
  • Dua solusi open-source populer: Fail2Ban (rule-based) dan CrowdSec (collaborative threat intelligence)
  • Belum ada perbandingan kuantitatif keduanya dalam konteks Docker environment

❓ Pertanyaan utama: Mana yang lebih efektif dan efisien untuk home server Docker — Fail2Ban atau CrowdSec?

⚖️ Analisis Komparatif

🛡️ Fail2Ban

✅ Kelebihan
  • Ringan, mudah dikonfigurasi
  • Tidak butuh koneksi internet
  • Mature, dokumentasi lengkap
  • Integrasi langsung dengan iptables
❌ Kekurangan
  • Hanya reaktif (rule-based)
  • 0 blocked IPs dalam eksperimen ini
  • Tidak ada threat intelligence
  • Efektivitas bergantung pada konfigurasi log path

🌐 CrowdSec

✅ Kelebihan
  • Collaborative threat intelligence
  • Mendeteksi 2 events (Fail2Ban: 0)
  • Risk score lebih rendah (6.62 vs 7.69)
  • CPU overhead lebih efisien
  • Proaktif: blokir IP dari komunitas global
❌ Kekurangan
  • Butuh koneksi internet untuk CTI
  • Setup lebih kompleks (bouncer key)
  • Bergantung pada komunitas CrowdSec

🏆 CrowdSec unggul dalam efektivitas mitigasi (35.7% vs 14.3% SSH reduction) dan efisiensi resource (CPU 6.26% vs 6.70%)
